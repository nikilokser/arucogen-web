# Веб-генератор ArUco: предлагаемая реализация

Репозиторий: https://github.com/nikilokser/arucogen-web
Исходный проект: https://github.com/GeBondar/aruco_map_generator

## Основной вариант
Статическое приложение, работающее в браузере, пригодное для GitHub Pages. Матрицы DICT_4X4_50 заранее генерируются OpenCV и сохраняются в проекте: результат совместим с исходником, сервер для генерации не нужен.

## Пользовательский сценарий
Пользователь загружает TXT исходного формата или редактирует таблицу маркеров (ID, размер в метрах, x, y). Справа отображается карта. Настраиваются масштаб и размер холста. Доступны скачивание SVG, PNG и TXT и загрузка примера исходного проекта.

## Совместимость
Сохраняются все восемь колонок TXT: id length x y z rot_z rot_y rot_x. Как в исходнике, z и углы не влияют на 2D-карту; интерфейс это явно сообщает. Начало координат находится в центре холста, положительный y направлен вверх. Значения по умолчанию: DICT_4X4_50, масштаб 1000 пикселей на метр, холст 2000 × 2000.

## Интерфейс
Русский язык, светлый интерфейс технического инструмента, адаптивная компоновка: настройки и таблица слева, большой предпросмотр справа. Статус ошибок с указанием строки. Подписи и сетка отображаются только в предпросмотре, не в экспортируемой карте.

## Проверки
Сравнение всех 50 матриц с OpenCV; тесты парсера, допустимых ID и размеров, координат и SVG; сборка и проверка импорта, редактирования и экспорта в браузере.

## Происхождение
В интерфейсе и README явно написано: «Веб-адаптация / производный форк GeBondar/aruco_map_generator», с активной ссылкой. Это описывает происхождение реализации; GitHub-репозиторий сам по себе сейчас пуст и не зарегистрирован как форк. В исходном проекте отсутствует файл лицензии; не назначается лицензия на чужой код.

## Альтернативы
1. Python + OpenCV на сервере: проще развивать дополнительные словари, но нужен отдельный хостинг сервера.
2. OpenCV.js в браузере: можно генерировать больше словарей, но библиотека тяжелее и требует проверки доступности ArUco в сборке.

## Граница первой версии
Один словарь, совместимый с исходником. Без учетных записей, хранения данных на сервере и 3D-преобразований.
