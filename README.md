# ArUco Web

**Веб-адаптация / производный форк [GeBondar/aruco_map_generator](https://github.com/GeBondar/aruco_map_generator).** Оригинальный генератор карт и алгоритм размещения созданы GeBondar. Эта версия переносит генерацию в браузер и добавляет интерфейс. Подробнее: [upstream/ORIGIN.md](upstream/ORIGIN.md).

## Возможности

- Карты маркеров OpenCV `DICT_4X4_50` (ID 0–49).
- Редактирование ID, размера и координат в таблице; полный TXT-редактор для восьми столбцов.
- Загрузка TXT и пример из исходного репозитория.
- Предпросмотр с сеткой, ID и масштабированием. Предупреждения о перекрытии и выходе за холст.
- Экспорт SVG, PNG и TXT. Данные остаются на устройстве; никаких аккаунтов, API и внешних шрифтов.

## Запуск

Нужен Node.js 20+. Приложение и сборка не имеют npm-зависимостей.

```sh
npm run dev
```

Откройте `http://127.0.0.1:5173`. Для автономного файла:

```sh
npm run build
```

Откройте `dist/index.html` двойным щелчком. Это один HTML-файл со встроенными стилями, кодом, словарём и примером. Его можно перенести на другое устройство или разместить на любом статическом хостинге. `npm run preview` обслуживает сборку локально.

## TXT и единицы

```text
# id length x y z rot_z rot_y rot_x
1 0.185 0.8 0.152 0 0 0 0
2 0.185 -0.8 0.152 0 0 0 0
```

`length` — полная сторона маркера в метрах, включая чёрную рамку, но без белого поля. `x` и `y` — координаты центра в метрах. Ось X направлена вправо, Y вверх. Начало координат — центр холста. Используйте точку в десятичных числах; допускаются научная запись, пробелы/табуляции и строки комментариев, начинающиеся с `#`.

`z`, `rot_z`, `rot_y`, `rot_x` сохраняются при импорте, редактировании таблицы и экспорте TXT. **Они не применяются к 2D-карте**, как и в исходном проекте. Их можно редактировать в TXT.

По умолчанию: 2000 × 2000 px, 1000 px/м. Холст: до 8192 px по стороне и 32 миллионов пикселей суммарно; до 1000 маркеров. Для распознавания оставляйте белый промежуток между маркерами и краями карты.

## Экспорт и печать

SVG содержит векторные прямоугольники, PNG имеет размер холста в пикселях. Сетка, оси и подписи ID не экспортируются. У маркеров, выходящих за холст, обрезаются края. Мелкие маркеры в PNG могут не распознаваться.

Масштаб `px/м` задаёт карту в пикселях, **не физический размер бумаги**. Для печати установите нужные размеры в программе печати или векторном редакторе и отключите автоматическое подгоняние страницы. Проверяйте размер напечатанного маркера линейкой.

## Проверки

```sh
npm test
npm run build
```

Браузерные проверки требуют Playwright (только для разработки):

```sh
npm install --no-save playwright
npx playwright install chromium
npm run test:browser
```

Проверяются импорт, редактирование, ошибки, сохранение восьми колонок, реальные скачивания и мобильная ширина. `TEST_URL` позволяет проверить запущенный сервер; `TEST_FILE` — абсолютный путь к автономному HTML. `CHROMIUM_PATH` задаёт путь к уже установленному Chromium; `PLAYWRIGHT_MODULE` — к доступному модулю Playwright.

Независимая проверка всех 50 матриц и экспортированного SVG через OpenCV:

```sh
python -m pip install opencv-python numpy
node tests/create-opencv-fixtures.mjs
python tests/verify_opencv.py
```

`python scripts/generate_dictionary.py` пересоздаёт `src/dictionary.js` из OpenCV. Python не нужен конечному пользователю.

## GitHub Pages

Workflow `.github/workflows/pages.yml` собирает сайт и публикует `dist/` при push в `main`, после успешных проверок. В репозитории один раз выберите **Settings → Pages → Source → GitHub Actions**. После успешного запуска сайт будет доступен по адресу `https://nikilokser.github.io/arucogen-web/`.

На pull request запускается отдельный workflow `checks.yml` с тестами, сборкой и браузерной проверкой; публикация выполняется только из `main`.

## Структура

`src/core.js` — TXT, проверка данных, размещение и SVG; `src/app.js` — интерфейс и PNG; `src/dictionary.js` — встроенные матрицы OpenCV; `scripts/` — автономная сборка и сервер; `tests/` — проверки; `upstream/` — исходник и авторство.
