# Происхождение

**arucogen-web — веб-адаптация / производный форк [GeBondar/aruco_map_generator](https://github.com/GeBondar/aruco_map_generator).**

Исходный автор: GeBondar. Зафиксирован исходный commit `b1e56d7f357979d0a3f890031e076299cf5196a5`.

В этой папке сохранены оригинальные `aruco_map_svg_gen.py` и `README.md` без правок. Оригинальный пример сохранён в `public/examples/aruco_map.txt` и встроен в `src/example.js`.

Из исходного проекта адаптированы:

- Формат TXT: `id length x y z rot_z rot_y rot_x`.
- Словарь `DICT_4X4_50`, чёрная рамка толщиной одна ячейка.
- Размещение по центру маркера, начало координат в центре холста, инверсия оси Y.
- Группировка соседних чёрных ячеек в прямоугольники для SVG.
- Значения по умолчанию: масштаб 1000 px/м и холст 2000 × 2000 px.

Матрицы для 22 словарей (9846 рисунков) получены через OpenCV 4.13.0. В веб-версии используется сетка ячеек выбранного словаря с чёрной рамкой вместо растра 100 × 100 пикселей. Для исходного DICT_4X4_50 это 6 × 6 ячеек. Это сохраняет рисунок маркера, даёт равные размеры ячеек и позволяет масштабировать SVG без потери качества. Результат не обещает побайтовое совпадение с исходным SVG. Фон всего холста белый.

Веб-интерфейс, дополнительные словари, генерация регулярной сетки, отдельное физическое поле для печати, валидация, предупреждения, экспорт PNG/TXT и автономная сборка добавлены в arucogen-web. Углы и z сохраняются, но не участвуют в 2D-рендере, как в исходном скрипте.

У исходного проекта на указанном commit нет файла лицензии. Лицензия на чужой код здесь не назначается; авторство и происхождение сохранены. Слово «форк» описывает производную реализацию: репозиторий nikilokser/arucogen-web не обязательно отмечен GitHub как fork.
