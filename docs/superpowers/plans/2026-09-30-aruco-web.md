# ArUco Web Implementation Plan

**Goal:** Реализовать утверждённый браузерный генератор в arucogen-web.
**Architecture:** Статический HTML/CSS и ES-модули. Таблицы OpenCV встроены, данные не отправляются на сервер.
**Tech Stack:** JavaScript, SVG, Canvas, Node.js 20+ для разработки и тестов.

## Constraints
DICT_4X4_50, исходные восемь столбцов TXT, размер в метрах, центр холста в начале координат, y вверх. Русский интерфейс. Явная атрибуция исходного проекта.

## Tasks
- [x] 1. Ядро и совместимость: tests/core.test.mjs проверяет parseMap, serializeMap, validateSettings, generateSvg; scripts/generate_dictionary.py создаёт src/dictionary.js через OpenCV. Ошибки показывают строку, ID допускаются от 0 до 49, размеры положительны. Сначала красный npm test, затем реализация src/core.js и зелёный тест.
- [x] 2. Реализация интерфейса: index.html, styles.css и src/app.js — таблица, TXT, загрузка файла, пример, настройки, SVG/PNG/TXT, сетка и подписи только в предпросмотре. tests/browser.mjs подготовлен для проверки действий и содержимого скачанных файлов, мобильной ширины и ошибок; запуск браузера в локальной среде запрещён, поэтому браузерная проверка пока не подтверждена.
- [ ] 3. Доставка: scripts/build.mjs копирует статическое приложение в dist, scripts/serve.mjs запускает локальный сервер; GitHub Actions проверяет тесты и публикует Pages. README и upstream/ORIGIN.md фиксируют происхождение, ограничения и команды. Финальные npm test, npm run build, браузерные проверки, независимое распознавание экспортов OpenCV; коммит, попытка отправки в origin, ZIP в outputs при отсутствии сетевого доступа.

## Visual system
Цвета: бумага #ffffff, рабочее поле #edf2f7, текст #172338, акцент #2459d3, рамки #d7e0eb, ошибка #b42318. Системный sans-serif, моноширинный только для TXT и чисел. Большой рабочий холст напоминает координатную карту; настройки компактные, без маркетинговых секций.

## Acceptance
Исходный пример импортируется без потери восьми колонок. Экспорт не содержит сетку или подписи. Маркеры распознаются OpenCV. Некорректные данные не дают скачать некорректную карту. Ширина 390px не создаёт горизонтальную прокрутку страницы.

## Verification status
Локально проходят 8 тестов ядра, сборка standalone HTML и независимая проверка OpenCV: совпадают все 50 матриц и все 50 маркеров экспортированного SVG распознаются. Review кода завершён без замечаний. Реальные браузерные скачивания PNG и мобильная ширина ещё не проверены из-за запрета запуска Chromium и открытия file://. Публикация в GitHub остановлена: доступ к GitHub через браузер не предоставлен, сеть shell ограничена. Доставка через HTML/ZIP подготовлена.
